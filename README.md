# NEXUS Retro Office 2.1

HD-Pixel-Art-Ausbaustufe des neuen NEXUS Dashboards.

## Konzept

- eigener Retro-RPG-/Pixel-Art-Stil
- 768 × 512 interne Canvas-Auflösung
- feinere Figuren, Möbel, Pflanzen, Monitore und Schatten
- 8 NEXUS-Charakter-Slots: James, Nora, Kevin, Gisela, Lina, Walter, Sarah, Finn
- Grid-Pathfinding
- klick-/touchbasierte Bewegung
- Idle / Wave / Arbeitsplatz / Meeting
- responsive für iPhone und Desktop
- kein Babylon.js, keine GLB-Modelle, keine 3D-Abhängigkeiten

Das bestehende NEXUS-Backend wird nicht verändert. Die Oberfläche bleibt eine reine Read-only-Preview und ist für eine spätere Projektion von Backend-Zuständen vorbereitet.
